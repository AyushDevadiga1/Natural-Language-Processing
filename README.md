# Natural Language Processing Journey

Welcome to my repository! This documents my personal journey and progress as I dive into the world of Natural Language Processing (NLP).

## What's Inside

Throughout this repository, you'll find various scripts and notebooks covering fundamental NLP concepts and techniques. Here is an overview of the tasks I've completed so far:

* **Introduction to NLP**: Covering the basics and foundational concepts (`intro_to_nlp.ipynb`).
* **Text Preprocessing in Action**: Fetching real-world movie data from the TMDB API and applying essential preprocessing steps. This includes lowercasing, removing HTML tags and URLs, handling emojis, removing stopwords, spell correction, and tokenization (`text_preprocessing_in_nlp.ipynb`).
* **Tokenization & Script Detection**: Breaking down paragraphs into sentences and words (tokens), applying filtering techniques, and identifying language scripts (`tokenization-filtering-and-script-detection.py`).
* **Stemming and Lemmatization**: Exploring techniques to reduce words down to their root or base forms to normalize text data (`stemming_and_lemmatization.py`).
* **Morphological Analysis**: Understanding the structure of words through inflectional and derivational analysis (`infectional-and-derivational-analysis-in-nlp.py`).
